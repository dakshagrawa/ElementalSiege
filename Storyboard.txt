ELEMENTAL SIEGE GAME STORYBOARD
Final Video Presentation Plan

OVERALL VIDEO LENGTH: 8-10 minutes
TARGET AUDIENCE: Educators, students, and project evaluators
STYLE: Professional yet engaging walkthrough with code explanations

SCENE BREAKDOWN:

SCENE 1: TITLE & INTRODUCTION (0:00-0:30)
- Visual: Game title screen with elemental icons (fire, water, earth, air) gently animating
- Visual: Creator names and class period displayed prominently
- Audio: Upbeat, adventurous background music begins
- Narration: "Welcome to Elemental Siege - an educational RPG that combines strategic gameplay with curriculum-based learning. I'm Daksh, one of the developers, and I'll walk you through how we built this game."
- On-screen text: "Elemental Siege - A Java Swing Educational RPG"

SCENE 2: GAME OVERVIEW & LOGIN FLOW (0:30-1:30)
- Visual: Demonstration of SignIn/SignUp screens
- Visual: Showcasing the PickAvatar screen with avatar options
- Narration: "Players begin by creating an account or logging in, then selecting an avatar that represents their journey through the game."
- Code Highlight: Brief snippet showing PageManager card layout system
- Visual: Transition to main game lobby/menu screen

SCENE 3: CORE GAMEPLAY MECHANICS (1:30-3:30)
- Visual: Battle screen layout with 4-panelGridLayout (User Info, User Card, Enemy Info, Action Area)
- Visual: Demonstration of element selection (clicking fire/water/earth/air icons)
- Visual: Show health bars updating based on correct/incorrect answers
- Narration: "The core battle mechanics are simple yet strategic: choose an elemental attack, answer a curriculum-based question correctly to deal damage, or incorrectly to take damage."
- Code Highlight: BattlePanel.java showing GridLayout setup and RelatedToBattlePanel class
- Visual: Backend logic - how answers are validated against QuestionPanel

SCENE 4: QUESTION SYSTEM DEEP DIVE (3:30-5:00)
- Visual: QuestionPanel showing different question formats (though currently text-based)
- Visual: Show how questions are retrieved from GameData
- Narration: "Questions are dynamically loaded based on subject areas and difficulty levels. The system pulls from a comprehensive database aligned with educational standards."
- Code Highlight: QuestionPanel.java showing question display and answer validation
- Visual: Demonstration of feedback system (correct answer animations vs incorrect)

SCEVE 5: TECHNICAL ARCHITECTURE (5:00-6:30)
- Visual: Diagram/animation showing how PageManager, GameData, Sound, and Panel classes interact
- Visual: Show CardLayout in action switching between screens
- Narration: "Under the hood, we used Java Swing's CardLayout for smooth screen transitions, MVC-like separation with PageManager managing state, and custom UI components for consistent styling."
- Code Highlight: PageManager.java showing card.show() method and panel management
- Visual: Sound system demonstration with background music playback

SCENE 6: CHALLENGES & SOLUTIONS (6:30-7:30)
- Visual: Side-by-side comparison - early buggy version vs final version
- Visual: Show specific challenges we encountered
- Narration: "Three major challenges we faced were: 1) Synchronizing game state between panels, 2) Image loading and rendering performance, and 3) Creating intuitive UI feedback systems."
- Visual: Solution demonstrations for each challenge
- Code Highlight: Specific fixes in GameData.java for state sharing
- Visual: Before/after of image loading with caching implementation

SCENE 7: EDUCATIONAL VALUE & FEEDBACK (7:30-8:30)
- Visual: Clips from our evaluator feedback sessions
- Visual: Show improvement suggestions implemented or planned
- Narration: "Based on feedback from educators and students, we confirmed the game's educational value while identifying areas for enhancement like visual elemental differentiation and hint systems."
- Visual: Quote from Evaluator 1: "Engaging educational tool that successfully blends learning with gameplay"
- Visual: Quote from Evaluator 2: "Solid foundation with clear educational intent"

SCENE 8: FUTURE ENHANCEMENTS & CONCLUSION (8:30-9:30)
- Visual: Concept art/mockups of planned features (save system, question bank, multiplayer)
- Visual: Roadmap showing short-term vs long-term goals
- Narration: "Moving forward, we plan to implement a save progress system, expand the question bank with multimedia elements, add more varied enemy types with elemental weaknesses, and create a teacher dashboard for tracking student progress."
- Visual: Final game screen with thank you message
- Audio: Music swells and fades out
- On-screen text: "Questions? Contact: daksh@example.com" and "Created for AP Computer Science Principles"

TECHNICAL DETAILS FOR CODE SNIPPETS:
- All code snippets will be displayed with syntax highlighting
- Each snippet will be on screen for 5-7 seconds with explanation
- We'll use zooming/panning to focus on relevant parts
- Snippets will come from actual project files with line numbers visible when helpful
